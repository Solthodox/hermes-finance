# Financial Modeling

Use when the task involves equities, accounting, valuation, earnings, or financial statements.

## Model discipline

- Pull primary filings and record the filing date/source.
- Separate historical facts from assumptions.
- Make revenue, margin, reinvestment, dilution, discount rate, and terminal assumptions explicit.
- Use sensitivity tables instead of one-point precision.
- Reconcile DCF, comps, and market-implied expectations before giving a recommendation.
